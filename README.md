# CI/CD 项目说明

这是一个基于 GitHub Actions 的 CI/CD 示例项目，使用 Go 语言和 Docker 实现自动化部署。

## 快速开始

**完整部署指南请查看：[DEPLOYMENT.md](DEPLOYMENT.md)**

## 项目结构

```
.
├── .github/workflows/
│   └── workflow.yml      # CI/CD 工作流配置
├── main.go               # 应用入口
├── handler/              # HTTP 处理器
├── test/                 # 测试文件
├── Dockerfile            # Docker 镜像配置
└── README.md             # 本文件
```

## CI/CD 流程

```
┌────────────────────────────────────────────────────────────────┐
│                        代码提交 (Push)                         │
└─────────────────────────┬──────────────────────────────────────┘
                          │
                          ▼
┌────────────────────────────────────────────────────────────────┐
│                      CI 阶段 (自动触发)                        │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  1. Build & Test                                        │   │
│  │     - go build                                          │   │
│  │     - go test                                           │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────┬──────────────────────────────────────┘
                          │ ✓ 通过
                          ▼
┌───────────────────────────────────────────────────────────────┐
│                   CD - 测试环境 (自动部署)                    │
│  ┌─────────────────────────────────────────────────────────┐  │
│  │  2. Build Docker Image                                  │  │
│  │     - 构建 Docker 镜像                                  │  │
│  │     - 推送到 ghcr.io                                    │  │
│  │                                                         │  │
│  │  3. Deploy to Staging                                   │  │
│  │     - SSH 登录服务器                                    │  │
│  │     - 拉取 latest 镜像                                  │  │
│  │     - 重启容器                                          │  │
│  └─────────────────────────────────────────────────────────┘  │
└─────────────────────────┬─────────────────────────────────────┘
                          │
                          │  打 Tag: git push origin v1.0.0
                          ▼
┌───────────────────────────────────────────────────────────────┐
│                  CD - 生产环境 (手动触发/Tag)                 │
│  ┌─────────────────────────────────────────────────────────┐  │
│  │  4. Deploy to Production                                │  │
│  │     - 构建带版本号的镜像                                │  │
│  │     - 部署到生产服务器                                  │  │
│  │     - （可选）需要人工审批                              │  │
│  └─────────────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────────────┘
```

## 触发条件

| 事件 | 触发条件 | 执行操作 |
|------|----------|----------|
| Push 到 main | `git push` | CI + 部署到 staging |
| Pull Request | PR 到 main | 仅 CI (build & test) |
| 创建版本 Tag | `git tag v1.0.0 && git push --tags` | 部署到 production（需启用） |

## 发布生产版本

```bash
# 测试验证后，打 tag 发布到生产环境
git tag v1.0.0
git push origin v1.0.0
```

> **注意**：生产部署配置默认是注释状态，详见 [DEPLOYMENT.md](DEPLOYMENT.md) 中的启用说明

## 开发流程

### 1. 创建功能分支

```bash
git checkout -b feature/user-login
# 开发...
git commit -m "feat: add user login"
git push origin feature/user-login
```

### 2. 创建 Pull Request

在 GitHub 上创建 PR 到 `main` 分支，CI 会自动运行构建和测试。

### 3. 合并后自动部署

代码审查通过后合并到 `main`，自动部署到测试环境。

## 技术栈

- **语言**: Go 1.26
- **框架**: Gin
- **容器**: Docker
- **镜像仓库**: GitHub Container Registry (ghcr.io)
- **CI/CD**: GitHub Actions
